# Участие в Serein

Коротко: собрать, прогнать те же проверки, что гоняет CI, и прислать правку одной понятной
темой. Ниже - что для этого нужно.

Об уязвимостях **не заводите issue**: порядок раскрытия описан в [SECURITY.md](SECURITY.md).

## Что нужно на машине

- Node **20.19+** или **22.12+** (проверено на 24), Rust **stable** (версия закреплена в
  `rust-toolchain.toml`), Tauri CLI 2.11.x.
- На Linux дополнительно: `libwebkit2gtk-4.1-dev`, `libayatana-appindicator3-dev`,
  `librsvg2-dev`, `libssl-dev`, `libudev-dev`, `patchelf`.
- Для интеграционных тестов - Docker.

```bash
npm install
npm run tauri dev
```

## Проверки перед отправкой

Ровно эти пять шагов гоняет CI на каждый пуш, и новое предупреждение роняет сборку:

```bash
npm run typecheck
npm run lint
npm test
cargo fmt --manifest-path src-tauri/Cargo.toml --check
cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings
cargo test --manifest-path src-tauri/Cargo.toml --lib
```

Интеграционные тесты идут против настоящих SSH-серверов в Docker. Они помечены `ignore`,
поэтому обычный `cargo test` их не трогает:

```bash
./scripts/ssh-stand/up.sh          # поднимает стенд и печатает переменные
cargo test --manifest-path src-tauri/Cargo.toml -- --ignored --test-threads=1
./scripts/ssh-stand/down.sh
```

`--test-threads=1` обязателен: тесты делят один `known_hosts.json`, а приложение переписывает
его целиком.

## Правка

- **Одна правка - одна тема.** Перестановку кода и смысловые изменения разносите по разным
  коммитам: иначе в обзоре не видно, где была ошибка.
- **Сообщение коммита - одна строка по-русски**, отвечающая на вопрос «что сделали?». Без
  префиксов вида `feat:` и без описания процесса.
- **Комментарии объясняют «почему», а не «что»**: в этом коде так принято, и правки, где
  комментарий пересказывает строку ниже, придётся переписывать.
- **Новое поведение - с тестом.** Исправление ошибки - с тестом, который без исправления падал.
- Строки интерфейса и сообщения об ошибках - на русском: локализации пока нет.

## Чего в проекте не будет

Облачная синхронизация, мобильное приложение, плагины и «чат с ИИ» внутри клиента. Это решение,
а не нехватка времени, - см. раздел ограничений в [README.ru.md](README.ru.md).
