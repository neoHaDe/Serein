## 1. Резюме

Serein — зрелый прототип «server workspace» с сильным Rust-бэкендом (russh, SFTP engine, lifecycle/cancel) и богатым UI. Для **1.1.0** продукт уже usable daily driver на LAN, но до «production-grade SSH-клиента» не хватает: **SSH Agent**, нормального **known_hosts UX**, **автотестов** на критичных путях, **Phase 0.3 reliability**, подписи/updater под новый релиз.

**Сильные стороны:** архитектура мультиплексирования SSH, SFTP pipeline + transfer manager, reconnect/cancel, Server Workspace, detach/reattach окон, DPAPI+vault, компактный installer (~6 MB).

**Главные риски:** почти нулевое тест-покрытие вне crypto; SFTP path validation только на `list`; TOFU без диалога; UI-заглушки (session logging); рассинхрон docs/PHASE0 с 1.1.0; updater на старый manifest.

## 3. Архитектура

### 3.1 Слои

```
WebView (React)  →  window.api (src/api/index.ts)  →  Tauri invoke/listen
                                                      →  lib.rs + модули Rust
```

| Слой | Объём (bytes, approx) | Комментарий |
|------|----------------------|-------------|
| Renderer TS/TSX | ~332 KB | Монолит `App.tsx` (~46 KB), `SftpPanel`, `styles.css` (~61 KB) |
| Rust backend | ~191 KB | Крупнейший: `sftp.rs` (~39 KB), `ssh.rs`, `lib.rs` (~806 строк) |

### 3.2 Rust-модули (`src-tauri/src/`)

| Модуль | Назначение |
|--------|------------|
| `lib.rs` | AppState, ~50 команд, teardown, windows_* |
| `ssh.rs` | russh: connect, ProxyJump, PTY, exec, ping, OpHub cancel |
| `sftp.rs` | SFTP: list/transfer/edit, slot pool, pipeline download, cancel |
| `store.rs` | JSON в `%APPDATA%/serein`, secrets split |
| `tunnels.rs` | -L / -D SOCKS5 / -R |
| `vault.rs`, `crypto.rs`, `dpapi.rs` | Мастер-пароль, scrypt/AES, DPAPI |
| `knownhosts.rs` | TOFU fingerprints |
| `workspace.rs`, `docker.rs`, `monitor.rs` | Server admin через exec |
| `pty.rs`, `term_out.rs` | Локальный терминал, батчинг вывода |

### 3.3 Frontend-маршруты (`main.tsx`)

Query-параметры открывают отдельные webview: `detachedTab`, `sftp`, `workspace`, `dockerLogs`, иначе `Gate` → `App`.

### 3.4 Состояние сессий

- `TerminalView.tsx`: module-level registry — xterm переживает remount (split/detach)
- `detachedSessions.ts`: не закрывать SSH при unmount main после detach
- Layout/aux geometry: persist через Rust store + `auxLayout.ts`

## 6. Безопасность (детально)

### 6.1 Хранение секретов

- **Flow:** password/passphrase → DPAPI blob → optional vault layer (scrypt + AES-256-GCM)
- **Verifier token:** `TERMINAL_VAULT_OK` в vault
- **IPC:** пароли приходят в invoke args при connect/save — стандарт для Tauri, но в памяти WebView до invoke
- **Private keys:** path from config, read from disk in Rust — без sandbox path

### 6.2 SSH / exec injection

| Команда | Санитизация |
|---------|-------------|
| workspace kill | pid > 1 |
| workspace systemctl | whitelist action + charset name |
| docker id | safe_id alnum |
| docker action | **partial** — action passthrough |
| monitor | fixed scripts |
| executeOnConnect | **none** — user/server config |

### 6.3 Known hosts

- SHA256 fingerprint, JSON store
- First connect: auto-trust
- Mismatch: connection rejected (good) but no «accept new key?» flow

### 6.4 Tunnels

- Bind 127.0.0.1 only (good for local forwards)
- Remote -R: forwarded TCP → localhost on server side
- Cancel wired in setup loops

## 7. Надёжность и async

### 7.1 Хорошо

- `teardown()` on disconnect: tunnels, transfers, ops, KI, disconnect
- SFTP cancel tears channel, not just UI flag
- Connect timeout 15s (configurable)
- SFTP op timeout 300s
- Exec output caps (512 KiB stdout)

### 7.2 Потенциальные leaks / слабые места

- `sftp_drag_out` — spawn без tracking при закрытии сессии
- `remoteedit` poll loop — temp dir cleanup on stop unclear
- Tunnel per-connection spawns — cleanup on session drop mostly via channel close
- Many `let _ = emit(...)` — silent failures to UI
