## Serein v0.1.0 (тогда ещё TermiNAL) 🚀

Первый релиз десктоп-клиента **SSH / SFTP «всё в одном окне»** на Tauri 2 + Rust.
Установщик — **≈ 3 МБ**, в простое ест **≈ 33 МБ** памяти (вместо 150–250 у Electron-аналогов).

### ✨ Что внутри

**Терминал** — несколько SSH-вкладок, сплит-панели, локальный терминал (PowerShell/cmd/WSL),
поиск, 17 тем, компактный режим, broadcast-ввод, восстановление вкладок, навигация по панелям с клавиатуры.

**Подключения** — пароль / ключ / **2FA** (keyboard-interactive), **ProxyJump-бастионы**,
**TOFU** known-hosts, командная палитра, импорт из `~/.ssh/config` и **PuTTY**.

**Файлы (SFTP)** — просмотр с хлебными крошками, инлайн-переименование, drag & drop,
рекурсивные передачи с прогрессом, двухпанельный режим, встроенный (CodeMirror) и внешний редактор.

**Туннели** — локальный `-L`, обратный `-R`, динамический SOCKS5 `-D`.

**Эксплуатация** — мониторинг CPU/RAM/диск/load и панель **Docker** (старт/стоп/логи/shell).

**Безопасность** — секреты через **DPAPI** + опциональный мастер-пароль (scrypt → AES-256-GCM),
зашифрованный бэкап `.tbk`, генерация ключей ed25519/RSA + `ssh-copy-id`.

### ⬇️ Установка

1. Скачайте **`TermiNAL_0.1.0_x64-setup.exe`** из раздела Assets ниже.
2. Запустите. В Windows 10/11 **WebView2** уже есть — ставить ничего больше не нужно.

> Сборка пока **не подписана** — SmartScreen покажет «Неизвестный издатель».
> Нажмите *Подробнее → Выполнить в любом случае*.

### ⚠️ Известные ограничения

- Нет цифровой подписи и авто-обновления.
- Не реализовано: аутентификация через SSH-агент / agent-forwarding, drag-out файлов на рабочий стол,
  UI списка/отмены передач.
- Сборки только под Windows (x64). macOS / Linux — в планах.

### 🛠 Под капотом

Tauri 2 (системный WebView2) · React 18 + TypeScript · Rust-бэкенд на
[`russh`](https://github.com/Eugeny/russh) / `russh-sftp` / `portable-pty`.
