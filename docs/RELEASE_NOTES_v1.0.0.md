## Serein v1.0.0

Первый выпуск под именем **Serein** (0.1.0 выходил ещё как TermiNAL).
Тот же стек: Tauri 2 + Rust + системный WebView2. Установщик **≈ 6 МБ** (сборка 1.0.0).

С 0.1.0: сессия переживает обрыв, долгие операции можно остановить, логи и SFTP живут в отдельных окнах, своя рамка вместо хрома Windows.

### Что нового с 0.1.0

**Сессия**
- Обрыв SSH (`drop`) отдельно от закрытия вкладки. Ручной reconnect и опциональный авто (до 5 попыток, бэкофф 1–15 с).
- При обрыве закрываются туннели, SFTP и PTY, без висящих задач.
- Отмена: конкретный файл SFTP, удалённый exec, создание туннеля, `docker logs -f`.

**SFTP**
- Большой download больше не грузится целиком в память (чанк под SSH-пакет, несколько READ в полёте).
- Панель можно открепить в окно ОС. Ctrl+колёсико зумит текст.

**Docker**
- Логи: цвет уровней, follow со стопом, широкая панель, открепить на второй монитор.

**Окна**
- Без рамки Windows — свой заголовок (свернуть / развернуть / закрыть).
- Магнит: стык вплотную и направляющие (края / центр). Группу тащит главное окно.
- Клик по любому окну поднимает все. По умолчанию одна кнопка на панели задач.

**Терминал**
- Сессия открывается после нормального fit; лишний resize PTY не шлётся — меньше дублей и «сжатого» TUI.

**Прочее**
- Лицензия Apache 2.0.
- CI на GitHub Actions (`tsc`, `cargo check`, `cargo test --lib`).
- Identifier `dev.serein.app`, данные в `%APPDATA%\serein`. Старый TermiNAL Windows не заменяет сам — это другое приложение; профиль `term-tauri` один раз переименовывается при запуске.

### Установка

1. Скачайте **`Serein_1.0.0_x64-setup.exe`** из Assets.
2. Или **Serein_1.0.0_x64-portable.exe** — один exe, без установки. Настройки в %APPDATA%\\serein.
3. Запустите. WebView2 на Windows 10/11 уже есть.

Сборка **не подписана**. SmartScreen: *Подробнее → Выполнить в любом случае*.
Проверяйте SHA-256 в Assets, если он приложен.

In-place с TermiNAL 0.1.0 не будет (другой identifier). Поставьте Serein рядом, данные подтянутся.

### Ограничения

- Только Windows x64. Нет подписи, на автообновление не рассчитывайте.
- Нет SSH-агента и agent-forwarding, нет drag-out на рабочий стол.
- Нет очереди передач (пауза / повтор / пачка файлов). Отмена текущего файла — есть.

### Под капотом

Tauri 2 · React 18 + TypeScript · [`russh`](https://github.com/Eugeny/russh) / `russh-sftp` / `portable-pty`.
